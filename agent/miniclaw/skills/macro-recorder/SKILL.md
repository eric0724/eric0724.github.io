# Macro Recorder — 巨集錄製與執行技能

## 功能概述

此技能提供完整的操作錄製與自動化執行功能：
1. 錄製滑鼠移動、點擊、鍵盤輸入
2. 儲存為可重複執行的巨集腳本
3. 支援單次執行或循環執行
4. 可調整執行速度與準確度

## 使用場景

- 重複性操作自動化（資料輸入、表單填寫）
- 遊戲日常任務錄製
- 軟體操作流程記錄
- 測試案例錄製

## 操作模式

### 模式 1：開始錄製
```
[macro-recorder record <巨集名稱>]
```
- 開始記錄所有滑鼠鍵盤操作
- 直到收到停止指令
- 儲存為巨集腳本

### 模式 2：執行巨集
```
[macro-recorder play <巨集名稱>]
```
- 載入並執行已儲存的巨集
- 支援單次或循環執行
- 可調整執行速度

### 模式 3：列出巨集
```
[macro-recorder list]
```
- 顯示所有已儲存的巨集
- 包含執行次數、建立時間

## 輸出格式

錄製中：
```
[RECORDING] 巨集錄製中
[ACTION] 滑鼠移動到 (960, 540)
[ACTION] 左鍵點擊
[ACTION] 鍵盤輸入：Hello World
```

執行中：
```
[START] macro-recorder 開始執行
[INFO] 巨集：每日登入
[ACTION] 執行步驟 1/10：移動到 (100, 200)
[ACTION] 執行步驟 2/10：點擊
...
[SUCCESS] 巨集執行完成
[COUNT] 已執行 1 次
```

## 與其他技能的協作

- **click-master**：使用精準點擊功能
- **calibration-master**：使用校準後的座標
- **safe_locate**：確保操作在安全範圍內

## 技術實作

- pynput 監聽滑鼠鍵盤事件
- JSON 格式儲存巨集腳本
- 支援執行速度調整（延遲設定）
- 可匯出/匯入巨集檔案
