# Click Master — 螢幕點擊專家

此技能提供精準的螢幕點擊操作指引，讓 AI 能執行從簡單到複雜的各種點擊任務。

## 觸發條件

當以下情境發生時，AI **應主動載入本技能**：
- 使用者要求點擊畫面上的特定元素（按鈕、圖示、連結）
- 需要進行多步驟的點擊操作（下拉選單 → 選項 → 確認）
- 座標基準的互動（例如「點擊 x=500, y=300 的位置」）
- 搭配截圖進行「所見即所得」式操作

## 輸出格式

AI 回覆時應使用以下格式明確表達點擊操作：

```
[點擊] 座標: (x, y) | 類型: single/double/right/hover | 說明: 描述點擊對象
```

### 參數說明

| 參數 | 型態 | 必填 | 說明 |
|------|------|------|------|
| `x` | 整數 | 是 | 螢幕 X 軸像素座標（左上角為 0） |
| `y` | 整數 | 是 | 螢幕 Y 軸像素座標 |
| `類型` | 字串 | 否 | 預設 `single`。可選：`single` / `double` / `right` / `hover` |
| `說明` | 字串 | 建議 | 描述點擊對象，用於日誌與驗證 |

## 座標取得策略

### 策略 A：直接指定座標（最低自由度）
當使用者已明確提供座標時，直接使用：

```
[點擊] 座標: (500, 300) | 說明: 確認按鈕
```

### 策略 B：元素描述 → 轉換座標（中等自由度）
當使用者描述元素但未給座標時，需先截圖分析：
1. 執行 `miniclaw:screenshot` 取得當前畫面
2. 分析畫面中元素位置（左側選單、中央內容區、底部工具列）
3. 估算合理的像素座標範圍
4. 輸出帶座標的點擊指令

### 策略 C：百分比相對位置（中等自由度）
適合不同解析度的螢幕：

```
[點擊] 座標: (50%, 75%) | 說明: 下一步按鈕（相對位置）
```
> 前端收到 `%` 標記時，自動依螢幕解析度轉換為絕對像素。

## 進階操作模式

### 1. 拖拽操作
從起點按住滑鼠，移動到終點後放開：

```
[拖拽] 起點: (200, 300) → 終點: (500, 300) | 說明: 拖動滑桿
```

### 2. 右鍵選單操作
右鍵點擊後等待選單彈出，再點選單項目：

```
步驟 1: [點擊] 座標: (400, 250) | 類型: right | 說明: 右鍵檔案
步驟 2: [點擊] 座標: (420, 320) | 說明: 選擇「內容」
```

### 3. Hover 預覽
滑鼠懸停指定位置：

```
[點擊] 座標: (300, 150) | 類型: hover | 說明: 懸停查看工具提示
```

## 校準與驗證

每次點擊後建議（特別是關鍵操作後）：
1. 再次截圖確認點擊結果
2. 比對預期畫面變化（按鈕狀態改變、選單出現、頁面跳轉）
3. 如未達預期，重新估算座標或嘗試降級策略

## 安全規則

- ⛔ 點擊座標不得超出螢幕範圍（x < 螢幕寬度, y < 螢幕高度）
- ⛔ 點擊前應確認目標非系統級危險區域（工作管理員、登出按鈕等）
- ⚠️ 右鍵與雙擊操作前，先輸出預覽說明讓使用者確認
