# Visual Trail — 視覺軌跡管理技能

## 功能概述

此技能提供完整的視覺軌跡追蹤與管理功能：
1. 即時追蹤滑鼠移動軌跡
2. 時間衰減機制（舊軌跡自動淡化）
3. 最大軌跡點限制（防止記憶體過載）
4. 視覺化顯示軌跡歷史

## 使用場景

- 滑鼠行為分析與監控
- 遊戲操作軌跡記錄
- UI/UX 測試軌跡可視化
- 自動化流程驗證

## 操作模式

### 模式 1：開始追蹤
```
[visual-trail start]
```
- 開始記錄滑鼠移動軌跡
- 即時視覺化顯示
- 直到收到停止指令

### 模式 2：停止追蹤
```
[visual-trail stop]
```
- 停止記錄軌跡
- 儲存軌跡資料
- 可選擇匯出

### 模式 3：分析軌跡
```
[visual-trail analyze]
```
- 分析軌跡統計數據
- 計算移動距離、速度
- 識別常用區域

## 輸出格式

追蹤中：
```
[START] visual-trail 開始追蹤
[INFO] 最大軌跡點：1000
[INFO] 衰減時間：60 秒
[ACTION] 軌跡點 #1: (100, 200) → (150, 250)
[ACTION] 軌跡點 #2: (150, 250) → (200, 300)
...
```

分析結果：
```
[SUCCESS] 軌跡分析完成
[TOTAL_POINTS] 1500
[TOTAL_DISTANCE] 1250 像素
[AVERAGE_SPEED] 45 像素/秒
[HOTSPOTS] (960, 540) - 125 次
[MEMORY] 使用 2.3 MB
```

## 與其他技能的協作

- **click-master**：記錄點擊軌跡
- **calibration-master**：視覺化校準過程
- **macro-recorder**：巨集執行軌跡追蹤

## 技術實作

- 時間衰減算法（指數衰減）
- 最大點數限制（LRU 淘汰）
- 記憶體優化（壓縮儲存）
- 可匯出 CSV/JSON 格式
