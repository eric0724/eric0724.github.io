1 下載小龍蝦執行器
📥 點這裡下載執行器（miniclaw-executor.zip）

解壓後最外層只需認 openminiclaw.bat（Windows）或 start.sh（Mac/Linux）；其餘程式在 app 資料夾，不用手動開。

2 點兩下 openminiclaw.bat，全自動啟動 🚀

進入資料夾，找到 openminiclaw.bat，直接點兩下。它會自動幫你完成所有設定並開啟網頁。

⚠️ 第一次執行常會自動安裝元件（例如 Node.js、ngrok）。若視窗關掉、沒有繼續跑、出現錯誤，或畫面提示要「重新開啟／reopen」：請先關閉該視窗，再重新點兩下 openminiclaw.bat。首次設定有時需重開 1～2 次 才會正常啟動並開啟網頁。
✅ 看到「[OK] Server started」就代表成功了！
⚙️ openminiclaw.bat 無法執行？點這裡展開手動步驟
① 安裝 Node.js（只需做一次）

⚠️ 成功安裝後，請重新開啟本頁面以確保功能正常。

winget install OpenJS.NodeJS
② 進入 app 資料夾，依序執行
cd app
npm install
node server.js
③ 另開視窗執行 ngrok
ngrok http 3000
還沒有 ngrok？先執行 winget install ngrok.ngrok，再去 取得 authtoken 設定。
3 確認連線
