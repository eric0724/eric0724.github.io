# 📋 小龍蝦 (Miniclaw) 本地端守護開發鐵律 (RULES_MINI.md)

本文件定義了「小龍蝦本地執行端 (Executor)」在執行、開發、寫入憑證與自我更新時，必須遵守的最嚴格技術規範。所有 AI 代理程式、代碼生成器與自動腳本均不得違反此鐵律，以確保使用者的電腦安全與程式自癒能力。

---

## 🛠️ 第一條：自動備份與還原守護 (Backup & Recovery)

1. **強制備份**：
   - 執行端 `server.js` 在啟動時，必須優先檢查同級目錄下是否存在 `server.js.bak`。
   - 若不存在，必須**立即拷貝**一份當前正在執行的 `server.js`，將其儲存為 `server.js.bak`。
2. **免死金牌還原**：
   - 網頁設定面板必須提供「自癒還原」按鈕。當點擊時，後台伺服器需自動讀取 `server.js.bak` 的內容，覆蓋當前的 `server.js`，並於 1.5 秒後重啟服務，以修復任何損毀。

---

## 🔒 第二條：增量寫入原則 (Add-Only Guard)

1. **金鑰安全隔離**：
   - 所有的 API 金鑰（OpenAI/Claude/Gemini/Groq）、LINE/Discord Channel Secrets 與 Webhook 連線設定，必須**嚴格存儲於外部憑證檔**：
     `miniclaw-executor/credentials/auth-profiles.json`
   - 嚴禁將金鑰、Token 硬編碼（Hard-Code）寫入到程式碼檔案中。
2. **非覆蓋寫入**：
   - 當網頁端或 API 要求更新/寫入憑證與設定時，`server.js` 必須採用增量寫入（Merge/Add-Only）。
   - 嚴禁覆蓋或刪除既有的核心路由、WebSocket 監聽器與系統操控指令。

---

## 🏷️ 第三條：指紋識別與代碼標記

1. **防護聲明首行**：
   - 任何生成的 `server.js` 或其修改版，其第一行必須強制寫入以下註解以供安全識別：
     ```javascript
     /* 警告：必須遵守 RULES_MINI.md 規範，嚴禁隨意變更此防線！ */
     ```
2. **故障自癒日誌**：
   - 每次觸發 API 故障轉移（401、429、500）或還原備份時，必須向控制台輸出帶有亮橘色（Warning Orange）的日誌記錄。

---

## ⚠️ 第四條：警告配色與訊息限制

1. **視覺反饋規範**：
   - 本專案所有攸關系統安全性、錯誤偵測或環境診斷的 UI/UX 反饋，必須統一使用 **亮橘色（Orange, HSL: 25, 100%, 50%）** 作為警示標記，不得隨意使用其他警示色。
2. **AI 回覆精簡化**：
   - 系統包裝傳送給 AI 的命令後，AI 回傳給網頁端的執行回覆文字（除長代碼或檔案輸出外），必須嚴格限制在 **100 字以內**，保持高效率且明快。
