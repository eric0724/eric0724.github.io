# test-lab

Miniclaw 行為測試沙盒。

這裡放的是「Miniclaw 收到使用者自然語言指令後，應該如何用滑鼠/鍵盤操控電腦」的範例腳本。
確認邏輯正確後才會整合進 Miniclaw 主系統。

---

## 腳本列表

| 檔案 | 任務說明 |
|------|----------|
| `desktop_folder_check.py` | 跳到桌面 → 截圖 → OCR → 找不到指定資料夾就右鍵新增，附 GUI 控制面板 |

---

## 開啟方式

### 1. 安裝依賴（只需做一次）
```bash
pip install -r requirements.txt
```
> 首次執行 OCR 會自動下載約 500MB 的語言模型，請耐心等待。

### 2. 執行腳本
```bash
python desktop_folder_check.py
```
畫面會彈出一個控制視窗。

---

## GUI 控制面板說明

| 按鈕 | 功能 |
|------|------|
| ▶ 開始 | 執行任務（跳桌面→截圖→OCR→找資料夾→沒有就右鍵新增） |
| ■ 停止 | 中斷正在執行的任務 |
| 🔲 選取範圍 | 拖曳框選螢幕區域，滑鼠操作與截圖只在此範圍內進行 |
| 🖥 全範圍 | 重置為整個螢幕 |
| ✕ 關閉 | 結束程式 |

---

## 任務完成後

腳本會在日誌區顯示：
```
📂 如何開啟剛建立的資料夾：
```
