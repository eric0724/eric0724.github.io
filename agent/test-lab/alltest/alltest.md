# Miniclaw 操作錄製與執行指引 (alltest.md)

> 當使用者需要自動執行腳本、錄製操作或自動化任務時，請遵循此份指引。
> ⚠️ **重要前置條件**：此功能（包含錄製、提取與自動化執行）**必須在「本地終端已連線 (WebSocket)」的情況下才能使用**。若為離線或純對話沙盒模式，此功能完全無法運作。

---

## 角色與符號標記規範

為了區分 Miniclaw 的背景處理工作與需要引導玩家進行的互動，請使用以下符號進行標記：

* `🤖` **[Miniclaw 自動執行/操作]**：代表 Miniclaw 可以透過終端直接在背景完成的事。
* `👤` **[玩家操作/對話引導]**：代表需要玩家手動配合，或由 Miniclaw 輸出在聊天對話框中對玩家說的話（提示詞字串通常會用 `>` 區塊標記）。

---

## 任務執行與引導流程

### 第一步：安裝與啟動錄製器 (🤖)

* 🤖 **[Miniclaw 操作]**：當玩家點擊大廳系統狀態列的「⏺️ 錄製操作」按鈕（或在對話中要求啟動錄製器時），Miniclaw 應直接透過連線的本地終端背景執行以下指令，全自動安裝依賴並開啟錄製工具：
  ```bash
  # 1. 背景安裝錄製依賴（僅在第一次時執行）
  py -m pip install pyautogui Pillow pynput opencv-python
  # 2. 啟動操作錄製工具
  py recorder.py
  ```

---

### 第二步：引導玩家進行錄製 (👤)

在錄製工具啟動後，Miniclaw 應在對話框中發送引導訊息：

> 👤 操作錄製器已成功在您的電腦上啟動！請照以下步驟進行錄製：
> 1. （選填）在錄製器頂端的「主要訊息」欄填入任務的整體描述（留空時，Miniclaw 將根據錄製的動作或其它步驟中的註解自動分析意圖）。
> 2. 點擊「▶ 開始錄製」（視窗會自動縮小）。
> 3. 開始正常操作您的電腦（點擊、鍵盤打字）。
> 4. 操作完成後，按下熱鍵 **F8** 停止錄製。
> 5. （選填）在錄製器步驟清單中，為步驟填寫說明（**無強制，可留空**）。
> 6. （選填）若有以下需要，可點擊「＋ 新增區域」框選特定畫面區塊並填寫說明：
>    * **位置不固定**：如某個視窗或按鈕的位置每次開啟會產生位移。
>    * **隨機事件區域**：例如遊戲中的「隨機怪物生成區」、「動態怪物出現區」，或需要對特定範圍進行目標搜索的區塊。
> 7. 點擊「✅ 完成，產出並複製給 Miniclaw」。
> 8. 請將剪貼簿中複製好的文字貼回來給我。

---

### 第三步：接收操作紀錄與解析

當玩家貼回紀錄文字後，Miniclaw 將解析其格式。文字格式範例如下：

```text
【主要說明】
原神自動化測試腳本

【操作紀錄】
1. 📍 標記點  (403, 745)
   → 這是主畫面按鈕 (說明為選填)
2. ⌨️ 輸入：w [press]
3. 🖱️ 點擊 左鍵  (160, 645)
4. 📦 標記區域  (333,727) → (378,762)
   → 這裡是隨機生怪與刷圖的監控區域
```

**操作類型解析對照表：**

| 操作類型 | STEPS 類型 | 說明 |
| :--- | :--- | :--- |
| `🖱️ 點擊` | `"click"` | 直接點擊指定座標 |
| `⌨️ 輸入` | `"write"` / `"press"` | 文字用 write，特殊按鍵用 press |
| `📍 標記點` | `"click"` | 點擊座標點 |
| `📦 標記區域` | `"locate"` | **圖案比對**。需要截圖並進行動態區域匹配 |

---

### 第四步：自動提取截圖 (🤖)

如果解析出來的操作步驟中包含 `📦 標記區域` (locate) 步驟：

* 🤖 **[Miniclaw 操作]**：Miniclaw 應自動透過終端執行以下指令，從錄製的暫存檔中提取並輸出截圖至 `captures/` 資料夾。**切勿叫玩家手動跑指令。**
  ```bash
  py extract_screenshots.py
  ```

---

### 第五步：生成自動化執行腳本 (🤖)

根據解析出的步驟，Miniclaw 於背景自動生成 `auto_run.py` 檔案。

#### 💡 圖案比對 (locate) 的搜尋範圍與信心度優化原則
在 `auto_run.py` 中，針對 `locate` 類型的步驟，其模式與範圍（radius）設定應根據**玩家的需求或實際場景動態判斷**，而非硬性限制為 ±300px：
* **普通跑位/視窗位移**：使用 `mode: "nearby"`, `radius: 200` 或 `300` 即可。
* **隨機大區域偵測（如生怪點、隨機彈窗）**：應由 Miniclaw 自動分析玩家場景，放寬 radius（例如 `radius: 500`），甚至將模式設為 `"full"` 全螢幕掃描以防漏失。
* **高精度點擊**：若為極小按鈕，應調高 `confidence` (預設 0.75，高精度調至 0.85)，以防誤觸。

```python
# 生成範例：
("locate", "captures/s1_region.png", "說明", {
    "origin": (333, 745),
    "mode": "nearby", # 根據生怪或位移場景動態選擇 "nearby" 或 "full"
    "radius": 300,    # 根據場景需求由 Miniclaw 自行調整大小
})
```

#### 💡 截圖上下文隔離原則
recorder.py 錄製時截取的範本圖片**一律是正常狀態（非 hover）**，確保比對時不受游標懸停顏色影響。Miniclaw 產出腳本時不需要處理 hover 狀態，直接使用 `screenshot_b64` 即可。

#### 💡 比對失敗處理
`auto_run.py` 的雙輪比對機制：
1. **第一輪**：原始像素比對（快速）
2. **第二輪**：縮放備援比對（嘗試 0.7x / 0.85x / 1x / 1.15x / 1.3x 五種縮放比例）

若兩輪都失敗，腳本會**停下來顯示錯誤視窗**，不會繼續執行。Miniclaw 應告知玩家：
- 試著調低設定裡的信心值（預設 0.75，可調至 0.6）
- 或重新錄製範本（畫面可能已改變）

---

### 第六步：執行腳本 (🤖)

* 🤖 **[Miniclaw 操作]**：當玩家點擊大廳系統狀態列的「▶️ 執行腳本」按鈕（或在對話中要求執行時），Miniclaw 應直接透過本地終端背景執行以下指令，全自動啟動腳本進行自動化點擊操作：
  ```bash
  py auto_run.py
  ```
