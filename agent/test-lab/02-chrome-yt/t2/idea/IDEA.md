# Capture Tool — 設計構想

## 背景

原本的計劃是透過影片自動偵測游標位置來裁切 UI 按鈕範本，
但遇到以下根本問題：
- 影片壓縮讓游標模糊，形狀比對無法辨識
- AI 回傳座標不準（GPT-4o 在 t1 中測試失敗）
- 光流法概念上與 AI 找座標相同，只是換了工具，核心問題沒有解決

## 新方向：視覺化標記工具

不從影片偵測游標，改成**讓使用者直接在螢幕上標記要裁切的位置**。

---

## 功能設計

### 主控制視窗（小型，永遠置頂）

```
┌─────────────────────────────┐
│   Miniclaw Capture Tool     │
│  ─────────────────────────  │
│  [+ 點擊點]  [+ 拖曳區域]   │
│  ─────────────────────────  │
│  📍 element_1  (點擊)  [刪] │
│  📦 element_2  (區域)  [刪] │
│  ─────────────────────────  │
│    [截圖全部]   [清除全部]   │
└─────────────────────────────┘
```

### 標記類型

| 類型 | 操作 | 說明 |
|------|------|------|
| **點擊點 (Click)** | 單擊螢幕 | 以點為中心固定大小裁切（預設 120x60px） |
| **拖曳區域 (Region)** | 拖曳畫矩形 | 以拖曳的矩形直接裁切 |
| 其他類型 | 待定 | 之後視需求加入 |

### 全螢幕半透明遮罩

- 使用者點擊「+ 點擊點」或「+ 拖曳區域」後出現
- 半透明黑色覆蓋整個螢幕（30% 透明度）
- **點擊模式**：滑鼠單擊 → 放下彩色圓點（附編號）
- **拖曳模式**：滑鼠拖曳 → 畫出彩色矩形框
- **Enter**：確認標記，關閉遮罩回到主視窗
- **ESC**：取消，關閉遮罩不儲存

### 截圖流程

1. 使用者按下「截圖全部」
2. 遮罩與所有標記消失（確保不被截進去）
3. 對每個標記位置截圖並裁切
4. 儲存為 `template_元素名_normal.png`（無游標版本）
5. 顯示截圖預覽讓使用者確認

### 換畫面繼續標記

- 截圖完成後，使用者可以切換畫面（例如打開 Chrome）
- 再次點擊「+ 點擊點」或「+ 拖曳區域」繼續新增標記
- 所有標記累積在同一個清單
- 最後統一「截圖全部」

## 技術實作

- **語言**：Python 3.8+
- **GUI 框架**：tkinter（全螢幕遮罩 + 主控制視窗）
- **截圖**：`pyautogui.screenshot()` / `PIL.ImageGrab`
- **存檔路徑**：`templates/` 資料夾（與現有結構一致）

### 主要類別

```
CaptureToolApp       主程式入口，管理主視窗與遮罩
ControlPanel         主控制視窗（標記清單、按鈕）
OverlayWindow        全螢幕半透明遮罩，處理滑鼠事件
Marker               資料類別（類型、座標、名稱）
CaptureEngine        截圖、裁切、儲存邏輯
```
