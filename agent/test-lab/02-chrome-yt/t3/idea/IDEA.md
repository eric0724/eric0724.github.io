# t3 — Miniclaw Recorder

## 方式說明

使用者錄製自己的操作，加上文字說明，整包傳給 Miniclaw 讓 AI 理解畫面和行為。

---

## 核心差異（對比 t1/t2）

| | t1 | t2 | t3 |
|---|---|---|---|
| **資料來源** | AI 看截圖猜座標 | 使用者手動標記靜態截圖 | 錄製真實操作（滑鼠+鍵盤） |
| **AI 涉入** | 找座標（不準） | 無 AI | 使用者決定傳什麼給 AI |
| **說明方式** | 無 | 每個標記填說明 | 主訊息 + 每筆操作填說明 |
| **輸出** | 範本圖片 | 範本圖片 | prompt 文字 + JSON |

---

## 流程

```
1. 玩家在「主要訊息」框寫整體說明
   例如：「這是一個打磚塊遊戲，底部有板子可左右移動...」

2. 按「▶ 開始錄製」
   → 監聽滑鼠點擊：記座標 + 截圖（點擊周圍 220x220px）
   → 監聽鍵盤：記按鍵序列（連續按鍵合併成一筆）

3. 按「■ 停止」或 F8（可自訂）結束錄製

4. 在每筆紀錄下方輸入說明
   例如：「這裡是開始按鈕」「左移後發射」

5. 用「＋ 新增點」/「＋ 新增區域」補充錄製沒捕捉到的地方
   → 全螢幕半透明遮罩，點擊或拖曳框選
   → 每次新增都要填說明

6. 按「📋 複製給 Miniclaw」
   → 產生格式化文字到剪貼簿
   → 貼到 Miniclaw 對話框，告訴 AI 要做什麼

7. 按「💾 匯出 JSON」存成檔案（含截圖 base64）
```

---

## 產生的 Prompt 格式

```
【主要說明】
這是一個打磚塊遊戲...

【操作紀錄】
1. 🖱️ 點擊左鍵 (320, 540)
   → 這裡是開始按鈕
2. ⌨️ 輸入：[left] [left] [space]
   → 左移兩格然後發射
3. 📦 標記區域 (0,0) → (200,150)
   → 這裡是怪物隨機生成的區域

【任務說明】
（玩家在這裡填：我要你幫我做一個...）
```

## 技術

- `pynput` — 監聽滑鼠/鍵盤（不需要焦點）
- `pyautogui` + `Pillow` — 截圖與繪製標記
- `tkinter` — GUI（深色主題，永遠置頂）
- F8（可換）— 熱鍵停止錄製，不需要點視窗
